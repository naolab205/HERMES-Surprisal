# Supplementary materials

Two real-data animations accompany Appendix A of the HERMES manuscript.

| Material | Research question | Recording interval |
|---|---|---|
| [S1 · Group contrast](extended/README.md#s1--time-course-of-the-row-level-eeg-contrast) | How does the high-minus-low row-surprisal voltage contrast change over time? | 0–2000 ms after observed row start |
| [S2 · Reader contrasts](extended/README.md#s2--between-reader-variation) | What reader differences does the group average conceal? | The same interval and ten readers |

[View both animations and their interpretation](extended/README.md).

S1 extends the temporal context of the main scalp analysis. S2 adds signed
sensor-level responses to the main reader-clustering summary. Both use the
frozen row-surprisal labels and training readings. Nine participants contribute
both books; sub-15 contributes GarnettDream only. This ten-reader extension
therefore differs from the balanced nine-reader analysis in the main figures.

The [source arrays](extended/extended_source_arrays.npz), source checks, and
rendering settings are retained with the two animations so that the supplement
can be reproduced. The main nine-reader arrays remain in
[`analysis/verified_revision_20261007/`](../../analysis/verified_revision_20261007/).
