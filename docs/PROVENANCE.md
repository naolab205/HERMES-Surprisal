# Source and evidence provenance

HERMES is the publication name for the hierarchical `MM_mid` EEG and eye model. The implementation and archived results come from the local foundation project, originally named `JBHI_Foundation_v2` and later `superisal_code`. Renaming does not define a new experiment or change its results.

The public package preserves model and training source, frozen numerical labels, primary out-of-fold predictions, fold-level comparison records, matched eye-control predictions, observation-window validation predictions, and scientific analysis arrays. Result files are copied from the research package, not regenerated model scores. Some historical reports and source snapshots retain the original local paths; they are provenance records.

The full original launch command and archived multimodal weights were not retained. The archived model used pooled unlabeled eye statistics. New runs use training-only statistics unless explicitly changed. Main data are repeated-reader, retrospectively explored item blocks. The sampled character centers were estimated from row timing, not verified character triggers. Physical-cache and fixed-grid experiments are separate protocols.

Large raw or processed signal caches, trained checkpoints, manuscript source, private keys, and personal machine configuration are not part of this repository. A small ten-second, eight-channel recorded EEG excerpt is included for the README replay, with extraction hashes and source identifiers. The public ChineseEEG dataset must be obtained from its provider. No repository-wide redistribution license has yet been designated; upstream data and model terms still apply.

README graphics were prepared with code. The architecture illustration contains author-arranged explanatory components prepared with AI assistance, as disclosed in the manuscript; data plots use saved numerical results. The release does not claim publication acceptance.

The header and architecture are static explanatory artwork generated with Pillow by `scripts/build_readme_artwork.py`. The two former conceptual-flow GIFs were retired to avoid repeating the same architecture animation.

The scalp supplement contains two recorded-data animations: S1 follows the group row-surprisal contrast, and S2 follows ten individual readers. Both cover 0–2000 ms after observed row starts using 39 measured 100-ms means advanced by 50 ms and displayed at 100 ms per frame. Nine readers contribute both books; sub-15 contributes GarnettDream only. They use training readings and frozen labels. Their ten-reader available-book average differs from the balanced nine-reader analysis in the main figures.

The supplement re-extracts continuous EEG with complete within-row coverage. Its source arrays, extraction provenance, rendering settings, and numerical precision check remain in `docs/appendix/extended/`. Extraction provenance records 582 physical-cache prefix checks and float32/float64 reduction differences without changing the published main summaries. The main nine-reader arrays and electrode coordinates remain in `analysis/verified_revision_20261007/`.

Unused four-window animations, duplicate static previews, and their retired rendering script were removed from the current release. The two retained GIF files and all model predictions are unchanged. Earlier supplementary numbering is superseded by S1/S2, matching the current manuscript Appendix A. No model training or new held-out evaluation was performed for this cleanup.

The repository overview separates the active model and reproduction entry points from archived experiment evidence. Superseded, unreferenced artwork and the obsolete preliminary analysis narrative were removed. Four console logs that were byte-identical to retained JSON records were also removed. Frozen result tables, predictions, numerical source arrays, experiment snapshots, and the original primary run log remain intact. The retired concatenated-row builder is a compatibility guard; its unreachable implementation was removed from the current entry while the historical snapshots remain.

The README measured-data displays are generated by `scripts/build_measured_data_animations.py`. One replays ten seconds of author-filtered ChineseEEG from a deterministically selected, audited training recording, with eight original-amplitude channels and an offline E62 spectrogram. The other recomputes seven empirical ROC curves from the unchanged archived prediction CSV and sweeps display thresholds without refitting or selecting a classifier. Each fold AUC is checked against the original table. These website demonstrations are separate from manuscript supplementary animations S1/S2; they add no new model results or temporal decoding claims. Source arrays, extraction identifiers, checksums, and per-frame confusion counts are retained in `docs/measured_demos/`.
