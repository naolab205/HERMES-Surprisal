# Tie-preserving item aggregation

The old pandas groupby mean could assign adjacent float64 values to exactly identical predictions repeated9 vs10 times. Spearman ranks can turn those rounding differences into spurious item/conditional correlation. Replace with p0 + mean(p - p0), preserving exact ties. Conditional strata with prediction range <=32*float64 epsilon*max(1,|p|) are undefined, never reported as positive correlations. Constant-prediction regression passed:20items with alternating9/10repeats remain exactly constant; conditional rho None. Book+slot oracle corrected conditional rho is undefined in both folds. Real neural scores unchanged to reported precision; raw trial predictions are untouched. Old historical oracle summaries using simple means should not be used as reliable conditional-metric evidence.
