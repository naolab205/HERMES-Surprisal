# Surprisal 单模型探索：时间对齐、窗口几何与真实脑电增量

本轮不集成，不改论文。固定原语言模型、192-token上下文、行级标签、句子分组清单；全部模型选择只用两个回顾性开发折0/3，seed2026。未启动七折三种子、新读者或外部测试。所有失败臂、预测、checkpoint、来源哈希和原缓存均保留。

## 1. 可定位的输入问题

旧长窗缓存把每行原始片段连在一起，却在截窗时只检查整个拼接数组边界。917096窗中213570窗（23.29%）跨行拼接边界。102268个同run拼接中95.68%原始时钟向后跳，重复进入下一行的信号。sub04两个书籍中2296/2388、8241/8624个行首旧基线与未来真实样本完全相同。已从实际连续128Hz记录重建完整缓存；所有未跨界窗口逐点相同，标签、记录、metadata和顺序不变。

Padding进入前端BatchNorm，使真实槽位特征随零槽位改变。新增valid-slot统计可消除这一变化；未启用时旧模型输出保持逐点一致。身份无关版本使用所有训练记录共享的CSD矩阵和幅度尺度，forward忽略记录编号。

这些是数据/输入修复，不能作为新架构创新或跨协议性能增益。

## 3. 决定性噪声检验

字符窗口的原始中心是 ROWS + char_slot*(行时长/槽数)。同一原始信号的重复样本间距携带SOA。不给模型duration标量，并不能去除这一线索。

噪声控制使用每条阅读独立的0.5–30Hz平稳高斯流，保留原窗口重叠间距和mask；不存在真实EEG、共享文本随机种子或EEG训练标签特征。训练预算/选择规则与真实模型相同。

干扰oracle只在训练期拟合：book+槽数+SOA的itemρ=.3713/.4077，条件ρ=.1816/.1489；增加标点前字符数后itemρ=.4144/.4623。Oracle是诊断，不是候选EEG输入。

## 4. 去除时长几何后的单模型实验

预注册固定.35s网格，用 ROWS + char_slot*.35s 截取连续EEG，不读取行末时刻、时长、SOA、文本或目标来确定窗口位置。这是固定采样约定，不是已验证字符触发时间。当前本地未找到逐字符刺激日志；原始触发事件不足以直接确立精确字符对齐。

新的完整缓存有19记录、917096窗、102499条阅读。匹配基线、11token位移模块、同网格噪声臂均已完成，模型按单次阅读验证ρ选epoch。

## 5. 其他失败与解释边界

- 旧缓存signed-latency探针未在两个开发设置稳定改善。
- 默认valid-slot normalization在旧输入仅小幅提高item，第二折条件ρ下降；行共享基线也未晋级。
- 实际连续来源的前向编码检验：fold0最大额外R²=.000661、max-stat置换p=.015；fold3=.000264、p=.675。没有通过两个分块的响应字典训练门槛，不开发目标/干扰响应字典。
- 指标修复：相同预测不同重复次数的普通浮点均值会制造极小差异，Spearman可能错误破同分。改用p0+mean(p-p0)，并排除数值常量的条件分层。book+槽数oracle的条件ρ现在应为未定义。新汇总使用修复，原始预测不改。
- fixed_aligned fold3出现AMP首次更新跳过的scheduler警告，损失与最终预测有限。该臂本身未晋级，不为此扩大重跑；任何后续候选晋级前必须记录有效优化步数并统一处理跳步。

## 6. 本轮决策与后续研究方向

保留连续来源修复、有效槽位统计、身份无关归一化和可靠指标。不保留时间模块为经过验证的算法增益，不更新论文或宣称ρ≥.5。

下一条专用架构路线应围绕“仅由EEG估计反应时相，再保守汇总重叠证据”开展，而不能继续使用行时长生成窗口。先验证两个便宜探针：

1. 训练数据中，无标签EEG能否恢复稳定刺激节律/相位，且优于相位打乱、平稳噪声；评估两个固定开发设置。元数据时长仅作离线诊断，不作为推理输入，也不按目标分数选择周期。
2. 在确定的真实时间基准上，加入surprisal是否提供超过视觉、版面、字符数和眼动协变量的稳定额外编码量。若未通过，继续定位标签粒度/事件对齐/信号质量，不开发响应模块。

只有两个探针通过，才实现由EEG决定时间对齐、按物理采样支持去重、用训练期验证的响应约束证据的单一模块，并与固定对齐、随机响应和同容量普通网络比较。该构想尚未实现或证明新颖性；它源于本轮噪声失效和字符对齐不确定性的直接证据。
