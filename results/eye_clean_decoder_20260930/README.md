# Eye-assisted EEG correction versus fusion: seven-fold decoder experiment

This is an exploratory downstream **row-surprisal decoding** comparison on
ChineseEEG, not an eye-to-ICA signal probe. It uses the same 7 contiguous,
item-disjoint blocks; each fold chooses its epoch by validation single-reading
Spearman and scores the held-out block once. Readers recur across blocks, and
these development blocks have previously informed model design.

The three arms share the character-locked EEG cache, hierarchical architecture,
surface Laplacian, seed (2026), optimizer, target, and folds:

1. `paired_eeg_only`: author-preprocessed EEG; no Eye model input.
2. `paired_eye_clean`: the same EEG-only decoder after training-only Eye-to-EEG
   ridge correction (`src/foundation/eye_clean.py`). For each recording group,
   at most 1,000 training EEG/Eye epochs fit a ridge map from normalized gaze
   x/y and pupil to EEG sensors. The intercept is retained. Only samples in the
   aligned -100..+800 ms overlap are corrected, and samples without valid Eye
   data remain unchanged. No surprisal labels, validation items, or test items
   enter the correction fit. This is additional correction **after** the
   dataset authors' ICA, not a reconstruction of their ICA procedure.
3. `paired_eye_fusion`: uncorrected EEG plus the original Eye branch, now with
   Eye channel standardization estimated from the training fold only.

The EEG-only fold 0 run exactly reproduced the archived `ABL_noeye` metrics.
Fresh EEG-only folds 1–6 independently verify the rest of that archive.
`scripts/summarize_eye_clean_decoder.py` checks all seven and creates
`paired_per_fold.csv` and `paired_summary.json`.

Inputs: `/data/2_readEEG/superisal_code/data_cache/char_epochs_1200ms/` and
`/data/2_readEEG/superisal_code/data_cache/eye_char/`; frozen labels:
`model_code/data_cache/surprisal_1829a99ad4.csv`.

The associated signal-level ICA probe is in
`results/eye_guided_ica_pilot_20260930/`; it is a separate analysis. The
decoder comparison is limited to one seed and the already explored item blocks.

## Test results

Values are seven-fold mean ± fold standard deviation. `paired_per_fold.csv`
contains all fold scores and signed paired differences; the predictions CSVs
under `tables/` contain every held-out row reading.

| Arm | Single-reading Spearman | Item Spearman | Item AUC | Item Δ versus EEG-only | Item positive folds |
|---|---:|---:|---:|---:|---:|
| EEG-only | 0.3544 ± 0.0207 | 0.3988 ± 0.0198 | 0.7434 ± 0.0127 | reference | — |
| Eye regression then EEG-only | 0.3523 ± 0.0218 | 0.3958 ± 0.0201 | 0.7420 ± 0.0146 | −0.0031 | 3/7 |
| EEG+Eye fusion, training-fold statistics | 0.3510 ± 0.0195 | 0.3974 ± 0.0161 | 0.7424 ± 0.0107 | −0.0014 | 2/7 |

The archived fusion arm using pooled unlabeled Eye statistics reached item
Spearman 0.4049 ± 0.0148; it is a distinct normalization policy, not the
train-only arm above. Neither the additional regression correction nor the
train-normalized fusion beat EEG-only on mean item Spearman here. The small
mixed fold differences do not justify a significance claim. This does not
evaluate eye-guided ICA before the authors' cleaning or a held-out reader/text
transfer set. Pupil covaries with cognition as well as ocular artifacts, so
the regression map may remove useful EEG variation.

## Reproduce

Run from `model_code/` with the prepared CogAlign Python environment and
`SURPRISAL_EYE_CACHE=/data/2_readEEG/superisal_code/data_cache/eye_char`.
All decoder arms used `scripts/run_charbag_cv.py --arch mmhier --seq-block
modern --csd --batch-size 64 --epochs 25 --patience 6 --seed 2026 --cache-dir
/data/2_readEEG/superisal_code/data_cache/char_epochs_1200ms`. Add `--no-eye`
for EEG-only, `--no-eye --eye-clean` for regression correction, or neither for
fusion. The EEG-only and correction arms each used one process for fold 0 and
another for folds 1–6; fusion ran all folds in one process. The listed table
and JSON are regenerated by `python scripts/summarize_eye_clean_decoder.py`.
