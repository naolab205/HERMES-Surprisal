# Surprisal 探索结果：2026-10-03

## 结论与边界

本轮完成监督修复和预注册的开发筛选，未找到可晋级的性能改进。没有达到 item ρ≥0.5，也没有形成经过验证的新架构贡献。论文未修改。仅使用回顾性开发划分，不把本次结果称为独立外部验证。

## 已完成的正确性修复

字符标签原为含标点贡献的 token 和，行标签按 token 数平均；原加载器按呈现槽位平均。已将局部贡献换算到槽位单位，并与冻结行标签校正。按真实 char_slot 对齐，不以数组前缀代替物理槽位。未知 token 截断、伪标点槽位和缺失事件的行屏蔽局部监督，仍保留行损失。75787 条开发训练/验证记录中 73198 条满足局部对齐；2589 条局部监督被屏蔽。标准化后最大行均值恒等误差 3.68e-7。

局部监督头为现有 EEG 字符表示的线性读出，未改动行级推理输入。修复与模块单元核验通过，训练源文件哈希与预注册快照一致。正确性修复不计作算法创新。

## 机制路线与停止决策

1. **细粒度监督：不晋级。** 真实标签相比同结构行标签对照的 item Δρ 为 −0.0164/+0.0033；条件 Δρ 为 −0.0266/−0.0123。真实标签第二折低于顺序打乱对照，不能把小幅单次阅读提升归因于字符定位。
2. **响应/时间模块：未进入训练。** 先前的受控编码诊断 pFWER=0.345/0.850，未通过响应字典机制门槛。本轮细粒度定位同样失败，因此按注册计划停止依赖该证据的模块设计。没有把未训练模块描述为消融失败，也没有证明所有时间模块都无效。
3. **训练期跨读者教师：探针不晋级。** 仅在每个外层开发划分的训练文本中进行五块交叉拟合，教师排除学生读者，标签残差化仅由内部拟合块估计。三个固定学生读者与匹配错配控制均完成；不读取外层验证/测试 EEG。

## 可支持的解释和后续必要证据

目前支持“EEG 对行级 surprisal 有预测相关性”，但不支持已提取出稳定的 surprisal 特有局部反应。书籍/长度相关预测较强，控制后的相关性较弱；这提示必须继续区分布局相关变化和目标独有信息，不能把未经检验的假设写成原因。

事件时间为呈现槽位估计，局部标签含折入的标点贡献，部分 token 到物理事件的映射不可恢复。最有价值的下一轮输入是原始 token—字符对齐与更精确的逐字符事件日志；只有核验这些材料后，才能重新注册更精细的时延机制假设。新标签目标必须单列，不能与冻结行目标比较后宣称提升。

没有候选通过开发筛选，因此按协议未启动七折三种子、留一读者或外部复现。未完成这些条件阶段不影响本轮停止决策，但它们仍是未来性能/泛化声称的必要证据。没有配对显著性或 rho≥0.5 的声称。
